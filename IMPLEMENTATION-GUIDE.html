N8N Automation

Your Outreach Machine

Email is your primary automation channel. LinkedIn/Instagram automation carries serious risks.

⚠️

Critical Compliance Warning

LinkedIn automation = Account bans. LinkedIn actively detects and bans automation tools. Use manual outreach only.
Instagram cold DMs = ToS violation. No compliant way to automate cold DMs. ManyChat only for comment-to-DM flows.
Cold SMS = Illegal. TCPA violations carry $500-1,500 penalties PER MESSAGE. Never cold text.

Channel Risk Assessment

Channel Automation Risk Level Recommendation
Email Cold outreach Low PRIMARY CHANNEL - Use Apollo + Lemlist + HubSpot
LinkedIn Connection requests High Manual only. N8N generates task lists, human executes.
Instagram Cold DMs Critical AVOID. Only use ManyChat for inbound comment-to-DM.
SMS Cold texting Illegal NEVER. Only text opted-in leads (appointment reminders).

N8N Workflow Architecture

# Lead Acquisition Pipeline (Daily at 8 AM) Apollo.io Search (50 leads/day, local service businesses) ↓ Hunter.io Email Verification ↓ HubSpot Create Contact (lead_source: "Apollo Outreach") ↓ Lemlist Add to Campaign ↓ Slack Daily Summary # Reply Handler (Webhook trigger) Lemlist Webhook (email reply received) ↓ Sentiment Detection ↓ IF positive → HubSpot Deal + Slack Alert IF negative → Mark Unqualified + Remove # Meeting Booked (Calendly webhook) Calendly Webhook ↓ HubSpot Create/Update Contact + Create Deal ↓ Slack Team Notification ↓ Gmail Prep Email to Sales

Implementation

Your 12-Week Launch Plan

Step-by-step timeline from setup to scale. Follow this exactly.

Phase 1 - Days 1-7
Foundation Setup
  • Deploy landing pages (HVAC, Roofing, Plumbing) to production domain
  • Add pricing section to each landing page
  • Set up Google Analytics 4 tracking
  • Configure Google Ads conversion tracking
  • Create HubSpot CRM with custom properties
  • Set up N8N workflows (lead acquisition, reply handler)
  • Configure Apollo.io + Hunter.io + Lemlist integrations
Phase 2 - Days 8-14
Campaign Launch
  • Create Google Ads campaigns (HVAC, Roofing, Plumbing)
  • Upload all keywords, ad copy, extensions
  • Launch campaigns with $100/day total budget
  • Start email outreach (50 emails/day to warm up)
  • Monitor search terms daily - add negatives
  • Begin LinkedIn manual outreach (20 connections/day)
  • Set up automated alerts for spend/conversions
Phase 3 - Weeks 3-4
Initial Optimization
  • Pause low-CTR keywords (<2%)
  • Increase bids on high-converting keywords
  • A/B test ad copy variations
  • Scale email outreach to 100 emails/day
  • Analyze reply rates - optimize subject lines
  • Adjust device bid modifiers based on data
  • Review Quality Scores - improve low performers
Phase 4 - Weeks 5-8
Scale Winners
  • Double budget on top-performing campaigns
  • Add Electrician campaign
  • Scale email outreach to 200 emails/day
  • Implement remarketing campaigns
  • A/B test landing page variations
  • Build case studies from first closed clients
  • Refine sales call script based on objections heard
Phase 5 - Weeks 9-12
Full Scale
  • Switch to Target CPA bidding (if 30+ conversions)
  • Expand to Phase 2 geographic markets (Texas)
  • Launch SEO content strategy (2 posts/month)
  • Scale email to full capacity (500+/day)
  • Add testimonial videos to landing pages
  • Implement referral program for closed clients
  • Document all SOPs for team scaling
