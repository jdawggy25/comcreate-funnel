## Design Notes

### Color Palette
Use ComCreate brand colors from existing site:
- Primary: Deep blue (professional, trustworthy)
- Accent: Orange or green (action, growth)
- Neutral: White, light gray backgrounds
- Text: Dark gray (#333) for readability

### Typography
- Headlines: Bold, modern sans-serif
- Body: Clean, readable sans-serif
- Size: Large on mobile for easy reading

### Imagery
- Hero: Local service professional at work OR handshake moment
- Case studies: Real photos of clients if possible, or realistic stock
- Icons: Simple line icons for features
- Screenshots: Dashboard/reporting examples

### Mobile Optimization
- 60%+ traffic will be mobile
- Tap-friendly CTA buttons (min 48px height)
- Collapsible FAQ accordions
- Single-column layout on mobile
- Click-to-call phone number prominent

### Page Speed
- Compress all images
- Lazy load below-fold content
- Target <3 second load time
- Use CDN for assets

## Tracking Requirements

### Google Analytics 4 Events
- `page_view` - all pages
- `scroll` - 25%, 50%, 75%, 100%
- `cta_click` - all CTA buttons (with labels)
- `form_start` - user begins form
- `form_submit` - successful submission
- `video_play` - testimonial videos

### Conversion Tracking
- Google Ads conversion on form submit
- Google Ads conversion on Calendly booking
- Facebook Pixel for retargeting
- HubSpot tracking code

### UTM Parameters
All traffic sources should use:
- `utm_source` (google, linkedin, email)
- `utm_medium` (cpc, organic, outreach)
- `utm_campaign` (specific campaign name)
- `utm_content` (ad variant or email)
