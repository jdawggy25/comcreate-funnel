## Above-the-Fold Elements

You have approximately 3 seconds to capture attention. 57% of users spend most of their time viewing above-the-fold content.

### Required Elements (Priority Order)

#### 1. Headline (Location + Service + Value)
- Must include city/region name for local relevance
- Clearly state the primary service
- Include unique value proposition or urgency element

**Example Structure:**
```
[Service Type] in [Location] - [Unique Value/Urgency]

"24/7 Emergency Plumbing in Austin - 30-Minute Response Guaranteed"
"Top-Rated HVAC Repair in Phoenix - Same Day Service Available"
```

#### 2. Subheadline (Benefit-Focused)
- Expand on the headline value proposition
- Address primary customer pain point
- Keep to 1-2 lines maximum

**Example:**
```
"Licensed technicians ready to solve your problem fast. No overtime charges."
```

#### 3. Primary CTA Button
- Position prominently above the fold
- Use contrasting color (see CTA section)
- Action-oriented copy
- Minimum 48px height for mobile

#### 4. Phone Number (Click-to-Call)
- Large, prominent placement
- Include "Call Now" or "Tap to Call" label
- Format: (XXX) XXX-XXXX for readability
- Consider animated attention-grabber

#### 5. Trust Indicators (Compact)
- Star rating with review count: "4.9 Stars (247 Reviews)"
- Google Verified/Guaranteed badge
- Years in business: "Serving [City] Since 2005"
- License number (abbreviated)

#### 6. Hero Image/Video
- Show actual technicians or real completed work
- Avoid generic stock photos of smiling workers
- Local imagery if possible (recognizable landmarks)
- Optimal: Before/after of completed work

### Above-the-Fold Layout Template

```
+------------------------------------------+
|  LOGO          PHONE (Click-to-Call)     |
+------------------------------------------+
|                                          |
|     [HEADLINE - Location + Service]      |
|     [Subheadline - Value Proposition]    |
|                                          |
|     [    PRIMARY CTA BUTTON    ]         |
|                                          |
|  [Star Rating] [Badge] [Years in Biz]    |
|                                          |
|     [Hero Image/Video Area]              |
+------------------------------------------+
```

### Desktop vs Mobile Above-the-Fold

**Desktop (1200px+ width)**
- Two-column layout acceptable
- Form can appear above the fold alongside hero content
- Phone number in header, CTA prominent

**Mobile (320-768px width)**
- Single column, stacked layout
- Sticky click-to-call button at bottom
- Collapsible form (tap to expand)
- Hero image reduced or background

## Social Proof Placement and Types

Displaying 5+ reviews can boost conversion rates by up to 270%. Strategic placement is critical.

### Types of Social Proof (Ranked by Impact)

#### 1. Google Reviews Integration
- Display actual Google reviews with photos
- Show aggregate star rating prominently
- Include review count: "4.8 Stars from 312 Reviews"
- Filter reviews by service type on service pages

**Placement Priority:**
1. Near primary CTA (highest impact)
2. Hero section (immediate credibility)
3. Mid-page after service description
4. Near form fields (reduces friction)

#### 2. Video Testimonials
- 30-60 second customer testimonials
- Show completed work results
- Include customer name and neighborhood
- Thumbnail with play button (auto-play off)

#### 3. Photo Testimonials
- Customer photo with quote
- Photos significantly increase recall and credibility
- Include name, location (neighborhood), service received
- Before/after project photos with customer approval

#### 4. Trust Badges and Certifications

**Industry-Specific Badges:**
- Google Verified (replacing Google Guaranteed Oct 2025)
- BBB Accredited Business
- HomeAdvisor/Angi Approved
- Yelp Verified
- Industry certifications (NATE for HVAC, etc.)

**Security/Quality Badges:**
- Licensed, Bonded, Insured
- Background Checked
- Drug-Free Workplace
- Manufacturer Certifications (Carrier, Trane, Kohler)

#### 5. Statistics and Social Proof Numbers
- "12,000+ Jobs Completed"
- "4,500+ Happy Customers"
- "Serving [City] for 25 Years"
- "Rated #1 in [Service] on Google"

#### 6. "As Seen In" Logos
- Local news station logos
- Local publications
- Industry association memberships
- Community sponsorships

### Strategic Placement Map

```
ABOVE THE FOLD:
- Star rating + review count (compact)
- 1-2 trust badges (Google Verified, BBB)
- Years in business

FIRST SCROLL (3-10 seconds):
- 2-3 featured testimonials with photos
- "Trusted by X customers" stat

MID-PAGE:
- Google Reviews carousel/widget
- Video testimonial
- Certification badges grid

NEAR FORM/CTA:
- 1 strong testimonial quote
- Security badges (Licensed, Insured)
- Satisfaction guarantee

FOOTER:
- Association memberships
- Full certification list
- Service area with local trust
```

### Review Display Best Practices

1. **Recency Matters**: Show reviews from last 30-90 days
2. **Service Matching**: Filter reviews to match page service
3. **Photo Inclusion**: Reviews with photos get 3x more engagement
4. **Response Display**: Show owner responses to reviews
5. **Negative Review Strategy**: 1-2 honest reviews (3-4 stars) with resolution shown increases trust

### Conversion Impact by Placement

| Placement | Conversion Lift |
|-----------|-----------------|
| Near CTA buttons | 15-25% increase |
| Above the fold | 10-20% increase |
| Near form fields | 42% increase (with badges) |
| Mid-page carousel | 8-12% increase |

## CTA Button Design

CTA buttons directly influence whether visitors take action. A well-designed CTA can increase conversions by 42% or more.

### Color Guidelines

**High-Converting Colors (by context):**

| Color | Hex Code | Best For | Psychology |
|-------|----------|----------|------------|
| Orange | #FF6B35 | Primary CTA, urgency | Energy, action |
| Red | #E53935 | Emergency services | Urgency, importance |
| Green | #43A047 | Eco-friendly, confirmation | Trust, go-ahead |
| Blue | #1976D2 | Professional services | Trust, reliability |
| Yellow/Gold | #FFC107 | Secondary CTA, attention | Attention, caution |

**Critical Rule: Contrast is King**
- CTA must contrast with page background
- Use complementary colors for maximum pop
- Test dark backgrounds with light CTAs and vice versa
- A/B test: Red vs green showed 21% lift for red in one study

### Size Specifications

**Minimum Dimensions:**
- Height: 48px minimum (mobile touch target)
- Width: 200px minimum for primary CTA
- Padding: 16px vertical, 32px horizontal
- Font size: 16px minimum (18-20px recommended)

**Desktop:**
- Primary CTA: 54-60px height
- Width: 220-300px or full-width on mobile

**Mobile:**
- Full-width buttons (with margin)
- Height: 54-60px for thumb-friendly tapping
- Sticky bottom CTA: Full-width, 56px height

### Copy Formulas

**First-Person Action Verbs (Higher Conversion):**
- "Get My Free Quote"
- "Schedule My Service"
- "Start My Repair"
- "Fix My [Problem]"

**Avoid:**
- Vague: "Submit", "Learn More", "Click Here"
- Generic: "Contact Us", "Get Started"

**High-Converting CTA Examples for Local Services:**

| Service | Primary CTA | Secondary CTA |
|---------|-------------|---------------|
| Emergency Plumbing | "Get Emergency Help Now" | "Call 24/7: (XXX) XXX-XXXX" |
| HVAC Repair | "Schedule Same-Day Service" | "Get My Free Estimate" |
| Electrical | "Book My Electrician" | "Request Free Quote" |
| Roofing | "Get Free Roof Inspection" | "See My Estimate" |

### Placement Strategy

**Primary CTA Locations:**
1. Above the fold (mandatory)
2. After value proposition section
3. After testimonials/social proof
4. Sticky footer on mobile

**Rule of 3:** Include primary CTA at least 3 times on page:
- Top (above fold)
- Middle (after compelling content)
- Bottom (final push)

### Visual Enhancements

**Effective Additions:**
- Subtle drop shadow for depth
- Hover state (color shift, slight scale)
- Micro-animation on load (subtle pulse)
- Arrow icon pointing right
- Phone icon for click-to-call

**Corner Radius:**
- Rounded corners: 4-8px (professional)
- Pill shape: Full radius (friendly, modern)
- Avoid: Sharp corners (feels aggressive)

### Supporting Elements

**Add Below CTA:**
- "Free Estimates" or "No Obligation"
- "Response in 15 Minutes" (urgency)
- "100% Satisfaction Guaranteed"
- Phone number alternative

**Example CTA Block:**
```
+----------------------------------------+
|                                        |
|    [ Get My Free Quote Today ]         |
|                                        |
+----------------------------------------+
     Or Call Now: (555) 123-4567
     *Response within 15 minutes
```

## Form Optimization

Forms with 3-5 fields have the highest conversion rates. Reducing from 11 to 4 fields produced a 120% increase in conversions.

### Optimal Field Count by Service

| Service Type | Recommended Fields | Conversion Impact |
|--------------|-------------------|-------------------|
| Emergency Services | 2-3 fields | Highest (speed priority) |
| Quote Requests | 3-4 fields | High |
| Appointment Booking | 4-5 fields | Moderate |
| Detailed Estimates | 5-6 fields | Lower (use multi-step) |

### Essential Fields Only

**Minimum Required:**
1. Name (first name only acceptable)
2. Phone number
3. Service needed (dropdown or radio)

**Optional but Valuable:**
4. Email (make optional if possible)
5. Address/ZIP (for service area verification)
6. Preferred time (morning/afternoon/evening)
7. Brief description (text area, optional)

**Avoid Asking:**
- Last name (unless legally required)
- Full address (unless scheduling)
- Multiple contact methods
- Detailed project scope

### Multi-Step Form Strategy

For complex services requiring more information:

**Step 1: Low Commitment (2 fields)**
- Service type selection
- ZIP code (validates service area)

**Step 2: Contact Info (2-3 fields)**
- Name
- Phone
- Email (optional)

**Step 3: Details (optional)**
- Additional comments
- Preferred schedule

**Progress Indicator Impact:** Showing progress bars increases completion by 20-30%.

### Form Layout Best Practices

```
+------------------------------------------+
|  Get Your Free Quote                     |
|  (Takes less than 30 seconds)            |
+------------------------------------------+
|                                          |
|  Name: [___________________________]     |
|                                          |
|  Phone: [___________________________]    |
|                                          |
|  Service Needed:                         |
|  [___________________________] (dropdown)|
|                                          |
|  [     Get My Free Quote     ]           |
|                                          |
|  [Lock Icon] Your info is secure         |
|  *We'll call within 15 minutes           |
+------------------------------------------+
```

### Form UX Enhancements

**Auto-Fill and Smart Features:**
- Enable browser auto-fill (10-50% higher completion)
- Phone number formatting
- Address autocomplete for ZIP
- Default to mobile keyboard for phone field

**Validation:**
- Inline real-time validation
- Green checkmarks on valid fields
- Clear, specific error messages
- Highlight error field (red border)

**Mobile Considerations:**
- Stack fields vertically
- Large input fields (44px minimum height)
- Appropriate keyboard types (tel, email)
- Avoid placeholder text as labels

### Trust Elements Near Forms

**Add Adjacent to Form:**
- Privacy statement: "We never share your info"
- Security badges: SSL, privacy policy link
- Review snippet: "Rated 4.9/5 by 300+ customers"
- Response time: "Average response: 8 minutes"

**Conversion Lift:**
- Trust badges near forms: +42% conversion
- Asking for phone number: -5% conversion (offset with value prop)

### Phone Number Considerations

Since asking for phone number can reduce conversions by 5%:

**Mitigation Strategies:**
1. Explain why: "For faster response"
2. Offer alternative: "Or email preferred"
3. Add trust signal: "No spam calls, guaranteed"
4. Show value: "We'll call within 15 minutes"

## Mobile-First Design Requirements

82.9% of landing page traffic is mobile. Mobile-first is mandatory, not optional.

### Core Mobile Requirements

**Screen Size Targets:**
- Primary: 375px width (iPhone standard)
- Test: 320px - 428px range
- Tablet: 768px breakpoint

**Touch Target Sizes:**
- Minimum: 44x44 CSS pixels
- Recommended: 48x48 CSS pixels
- CTA buttons: 54-60px height
- Spacing between targets: 8px minimum

### Click-to-Call Implementation

**Requirements:**
1. Phone number linked with tel: protocol
2. "Tap to Call" or "Call Now" label
3. Phone icon for visual identification
4. Prominently visible without scrolling

**Code Example:**
```html
<a href="tel:+15551234567" class="click-to-call">
  <span class="phone-icon">📞</span>
  Tap to Call: (555) 123-4567
</a>
```

**Placement:**
- Header (persistent)
- Sticky bottom bar
- After key content sections
- As alternative to form submission

### Sticky Bottom CTA Bar

**Recommended Implementation:**
```
+----------------------------------------+
|  [Phone Icon] Call  |  [Form] Quote    |
|        Now          |                  |
+----------------------------------------+
```

**Specifications:**
- Fixed position at screen bottom
- Height: 56-64px
- Full-width (100%)
- Semi-transparent or solid background
- Z-index: 1000+ (above content)
- Disappear on scroll up (optional)

**Conversion Impact:** Sticky CTAs increase mobile conversions by 6-18%.

### Thumb Zone Design

**Optimal Touch Zones:**
```
+------------------+
|   Stretch Zone   |  <- Hard to reach
|                  |
|   Natural Zone   |  <- Easy touch
|                  |
|   Primary Zone   |  <- Most accessible
+------------------+
    [Sticky CTA]     <- Ideal placement
```

**Design Principles:**
- Primary CTAs in bottom 1/3 of screen
- Secondary actions in middle zone
- Navigation/back buttons in top zone
- Avoid corners (hardest to reach)

### Mobile Form Optimization

**Input Field Specifications:**
- Height: 48px minimum
- Font size: 16px minimum (prevents iOS zoom)
- Full-width inputs (with padding)
- Generous padding: 12-16px internal

**Keyboard Optimization:**
```html
<input type="tel" inputmode="numeric" pattern="[0-9]*">
<input type="email" inputmode="email">
<input type="text" autocomplete="name">
```

### Mobile Page Structure

**Single Column Layout:**
```
+------------------------+

+------------------------+
|      Hero Image        |
+------------------------+
|    Headline + Sub      |
+------------------------+
|    Primary CTA         |
+------------------------+

|    Services List       |

|    Testimonials        |
+------------------------+
```

### Mobile-Specific Features

**Collapsible Sections:**
- Use accordions for FAQs

## Page Speed Requirements

A 100ms delay reduces conversions by 7%. Page load time must be under 3 seconds, ideally under 1 second.

### Core Web Vitals Thresholds (2025-2026)

| Metric | Good | Needs Improvement | Poor |
|--------|------|-------------------|------|
| LCP (Largest Contentful Paint) | <2.5s | 2.5-4.0s | >4.0s |
| INP (Interaction to Next Paint) | <200ms | 200-500ms | >500ms |
| CLS (Cumulative Layout Shift) | <0.1 | 0.1-0.25 | >0.25 |

**Note:** INP replaced FID in March 2024 as the responsiveness metric.

### Google Ads Quality Score Impact

Landing page experience is 1 of 3 Quality Score components:
1. Expected CTR
2. Ad relevance
3. **Landing page experience** (includes speed)

**Speed Impact on Ads:**
- Faster pages = Higher Quality Score
- Higher Quality Score = Lower CPC
- Lower CPC = Better ROI on ad spend

**2025 Update:** Google now uses advanced prediction models for navigation experience, penalizing confusing or slow landing pages more heavily.

### Speed Optimization Checklist

**Images:**
- [ ] Compress all images (TinyPNG, ImageOptim)
- [ ] Use WebP format with fallbacks
- [ ] Implement lazy loading for below-fold
- [ ] Specify width/height to prevent CLS
- [ ] Use responsive images (srcset)
- [ ] Target: <100KB per image

**Code:**
- [ ] Minify CSS and JavaScript
- [ ] Remove unused CSS
- [ ] Defer non-critical JavaScript
- [ ] Inline critical CSS
- [ ] Reduce third-party scripts

**Server:**
- [ ] Enable GZIP/Brotli compression
- [ ] Leverage browser caching
- [ ] Use CDN for static assets
- [ ] Enable HTTP/2 or HTTP/3
- [ ] Consider edge rendering

**Fonts:**
- [ ] Use system fonts when possible
- [ ] Preload critical fonts
- [ ] Use font-display: swap
- [ ] Limit font weights/styles
- [ ] Subset fonts if needed

### Mobile Speed Priority

**Target Metrics:**
- First Contentful Paint: <1.8s
- Largest Contentful Paint: <2.5s
- Time to Interactive: <3.0s
- Total page weight: <1MB (ideally <500KB)

**Testing Tools:**
1. Google PageSpeed Insights
2. GTmetrix
3. WebPageTest
4. Lighthouse (Chrome DevTools)
5. Google Search Console Core Web Vitals report

### Performance Budget

| Asset Type | Max Budget |
|------------|------------|
| HTML | <50KB |
| CSS (total) | <100KB |
| JavaScript (total) | <300KB |
| Images (total) | <500KB |
| Fonts | <100KB |
| **Total Page** | **<1MB** |

### Speed vs Features Trade-offs

**Remove or Defer:**
- Video auto-play (use click-to-play)
- Heavy animations
- Chat widgets (load after interaction)
- Social media embeds
- Multiple third-party scripts

**Keep but Optimize:**
- Review widgets (async load)
- Form validation (inline JS)
- Analytics (async, minimal)
- Click-to-call functionality

### Only 47% of websites pass Core Web Vitals

This represents a significant competitive advantage for optimized pages. Passing Core Web Vitals means:
- Better search rankings
- Lower ad costs
- Higher conversion rates
- Improved user experience

## Headline Formulas

Headlines can boost conversions by 90% or more when optimized correctly. CityCliq saw 90% lift from one headline change.

### Core Formula Structure

**For Local Services:**
```
[Service Type] + [Location] + [Unique Value/Urgency]
```

### Proven Headline Formulas

#### 1. Location + Service + Benefit
```
[City] [Service] - [Key Benefit]

Examples:
"Austin Emergency Plumbing - 30-Minute Response"
"Phoenix HVAC Repair - Same Day Service Guaranteed"
"Dallas Electricians - Licensed & Available 24/7"
```

#### 2. Problem-Solution
```
[Problem]? [Solution] in [Location]

Examples:
"Broken AC? Fast HVAC Repair in Houston"
"Clogged Drain? 24/7 Plumbers Serving Chicago"
"Electrical Emergency? Licensed Help in Minutes"
```

#### 3. How-To (Implicit)
```
Get [Desired Outcome] with [Location]'s [Qualifier] [Service]

Examples:
"Get Fast Plumbing Repairs from Atlanta's Top-Rated Team"
"Get Your AC Fixed Today by Denver's #1 HVAC Company"
```

#### 4. Social Proof Lead
```
[City]'s [Rank/Rating] [Service] - [Credential]

Examples:
"Seattle's #1 Rated Plumber - 500+ 5-Star Reviews"
"Top-Rated HVAC in Miami - 4.9 Stars on Google"
"Phoenix's Most Trusted Electricians Since 1995"
```

#### 5. Urgency + Benefit
```
[Urgent Action] - [Benefit] [Location Qualifier]

Examples:
"Call Now - Same Day HVAC Repair in San Diego"
"Emergency Plumbing Help - No Overtime Charges in Boston"
"24/7 Electrical Service - Fast Response Across Tampa"
```

#### 6. Value Proposition First
```
[Primary Value] - [Service] in [Location]

Examples:
"No Job Too Small - Handyman Services in Portland"
"Flat-Rate Pricing - Honest Plumbing in Las Vegas"
"Free Estimates - Expert Roofing Across Nashville"
```

### Headline Power Words

**Urgency:** Emergency, Now, Today, Fast, Quick, Immediate, Urgent
**Trust:** Licensed, Certified, Insured, Guaranteed, Trusted, Proven
**Value:** Free, Affordable, No-Cost, Save, Discount
**Quality:** Expert, Professional, Top-Rated, #1, Best, Premier
**Local:** Your, Local, Nearby, [City Name], Serving [Area]
**Action:** Get, Call, Schedule, Book, Request, Fix

### Subheadline Best Practices

Subheadline should expand on headline with:
- Additional benefit
- Credential or social proof
- Objection handler

**Examples:**
```
Headline: "24/7 Emergency Plumbing in Austin"
Subheadline: "Licensed plumbers with 4.9-star rating. No overtime charges, ever."

Headline: "Phoenix's Top-Rated HVAC Repair"
Subheadline: "Same-day service by NATE-certified technicians. 100% satisfaction guaranteed."
```

### Headlines to Avoid

**Too Vague:**
- "Quality Service You Can Trust"
- "Your Local Home Service Experts"
- "Professional and Reliable"

**Commodity Phrases:**
- "Best Service at Affordable Prices"
- "Great Customer Service"
- "We're Here for You"

**Missing Location:**
- "Emergency Plumbing Services" (add city)
- "HVAC Repair and Installation" (add location)

### Testing Headlines

Headlines should be your first A/B test:
1. Test location placement (beginning vs end)
2. Test urgency level (emergency vs standard)
3. Test benefit focus (speed vs price vs quality)
4. Test social proof inclusion

## Ethical Urgency and Scarcity Tactics

68% of millennials make purchases within 24 hours when influenced by FOMO. Limited-time offers can increase conversions by 35%+.

### Ethical vs Unethical Tactics

**Ethical (Do This):**
- Real limited-time promotions
- Genuine availability constraints
- Honest scheduling limitations
- Seasonal offers with real end dates
- Actual capacity limitations

**Unethical (Never Do This):**
- Fake countdown timers that reset
- False "only 2 spots left" claims
- Manufactured urgency
- Misleading scarcity claims
- Pressure tactics without basis

### Approved Urgency Tactics

#### 1. Real-Time Availability
```
"3 appointments available today"
"Next available: 2:30 PM today"
"Currently serving 4 customers in your area"
```
Must be accurate and update dynamically.

#### 2. Seasonal/Time-Based Offers
```
"Winter Special: 15% Off Furnace Tune-Up (Ends Feb 28)"
"Spring AC Checkup - Book by April 15 for $99"
"Holiday Hours: Emergency Service Available Christmas Day"
```
Real deadlines with genuine offers.

#### 3. Capacity-Based Messaging
```
"Limited technicians available this weekend"
"High demand in [neighborhood] - call for earliest slot"
"Peak season: Book 2-3 days in advance"
```
Only use when genuinely at capacity.

#### 4. Time-Sensitive Benefits
```
"Call before 12 PM for same-day service"
"Request quote today, get response in 15 minutes"
"Book this week, installation next week"
```
Focuses on speed benefit, not false urgency.

### Countdown Timer Guidelines

**When to Use:**
- Real promotional end dates
- Seasonal offer deadlines
- Event-specific timing
- Limited-time guarantees

**When NOT to Use:**
- General lead capture pages
- Evergreen service pages
- When timer would reset on revisit
- Without a genuine deadline

**Implementation:**
```
"$50 Off Any Repair - This Week Only"
[Countdown Timer: 3d 14h 22m]
"Use code SAVE50 at time of service"
```

### Scarcity for Service Businesses

**Legitimate Scarcity Examples:**
- "Only 2 technicians certified for this repair"
- "Limited evening appointments available"
- "Manufacturer rebate expires [date]"
- "Last chance for pre-season pricing"

**Communicate Why:**
Always explain the reason for scarcity:
- "Due to high demand in [area]..."
- "Our licensed specialists are booking up..."
- "Manufacturer promotion ending..."

### Trust-Preserving Urgency Language

**Instead of:** "Call NOW or miss out!"
**Use:** "Same-day service available - schedule your appointment"

**Instead of:** "Only 1 left!"
**Use:** "High demand today - call for current availability"

**Instead of:** "Limited time only!"
**Use:** "Spring special through April 30"

### Testing Urgency Elements

Test these variations:
1. Page with urgency vs without
2. Different urgency messages
3. Countdown timer placement
4. Urgency in headline vs body
5. Different scarcity framings

Track both conversion rate AND customer satisfaction post-conversion.

## A/B Testing Priorities

Start with high-impact elements. Headlines could have the biggest impact on conversion rates.

### Testing Priority Framework (ICE)

**I - Impact:** How much will this change affect conversions?
**C - Confidence:** How confident are we this will work?
**E - Ease:** How easy is it to implement and test?

### Recommended Test Order

#### Priority 1: Headlines (Test First)
**Why:** First thing users see, 80% never scroll past
**Test Variables:**
- Location placement (beginning vs end)
- Urgency level
- Benefit focus (speed, price, quality)
- Social proof inclusion
- Question vs statement

**Example Test:**
- A: "Austin Emergency Plumbing - 30-Minute Response"
- B: "30-Minute Response Plumbing in Austin"

#### Priority 2: CTA Buttons
**Why:** Direct impact on conversion action
**Test Variables:**
- Button color (red vs green vs blue)
- Copy ("Get Quote" vs "Get My Free Quote")
- Size and prominence
- Placement (number of CTAs)
- First-person vs second-person language

**Example Test:**
- A: "Get Quote" (green)
- B: "Get My Free Quote" (orange)

#### Priority 3: Form Design
**Why:** Point of conversion, highest friction
**Test Variables:**
- Number of fields (3 vs 5)
- Field order
- Required vs optional fields
- Single-step vs multi-step
- Form placement on page

**Example Test:**
- A: 5-field form (name, email, phone, service, message)
- B: 3-field form (name, phone, service)

#### Priority 4: Social Proof
**Why:** Builds trust, reduces hesitation
**Test Variables:**
- Review display style (carousel vs grid)
- Placement (above fold vs mid-page)
- Number of reviews shown
- Photo inclusion
- Video testimonials vs text

#### Priority 5: Page Layout
**Why:** Overall user experience
**Test Variables:**
- Hero image vs video
- Content order
- Whitespace and density
- Mobile layout variations

### Testing Best Practices

**Test Duration:**
- Minimum: 2 weeks
- Recommended: 2-4 weeks
- Must capture full business cycle

**Statistical Requirements:**
- Confidence level: 95% minimum
- Statistical power: 80% minimum
- Sample size: Calculate before testing

**Sample Size Guidelines:**
| Current CVR | Minimum Visitors per Variation |
|-------------|-------------------------------|
| 2% | 3,000+ |
| 5% | 1,200+ |
| 10% | 600+ |
| 15% | 400+ |

### Common Testing Mistakes

1. **Testing multiple elements at once** - Can't isolate impact
2. **Ending tests too early** - False positives/negatives
3. **Ignoring statistical significance** - Making decisions on noise
4. **Not documenting results** - Losing learnings
5. **Testing low-traffic pages** - Never reach significance

### Test Documentation Template

```
Test Name: [Descriptive Name]
Hypothesis: [If we change X, then Y will happen because Z]
Start Date: [Date]
End Date: [Date]
Control: [Description of A]
Variation: [Description of B]
Primary Metric: Conversion Rate
Secondary Metrics: [Bounce rate, time on page, etc.]
Results: [Winner, confidence %, lift %]
Learnings: [What we learned]
Next Steps: [Follow-up tests or implementation]
```
