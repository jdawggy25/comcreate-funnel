Recommended Form Fields

Optimal: 3-4 fields maximum. Reducing from 11 to 4 fields can increase conversions by 120%.
  1. Name (required) - First name only acceptable
  2. Phone (required) - Add helper text: "We'll call to confirm"
  3. Service Needed (required) - Dropdown
  4. Email (optional) - Mark clearly as optional

6 Implementation Checklist

Designer Checklist

  • Headline includes location + service + value proposition
  • Phone number prominently displayed (click-to-call on mobile)
  • Primary CTA visible without scrolling
  • CTA button minimum 48px height (56px on mobile)
  • Trust badges above the fold (reviews, license, years)
  • Form has 3-4 fields maximum
  • Form inputs minimum 48px height, 16px font
  • Mobile layout is single column
  • Sticky header with phone on mobile
  • Sticky bottom CTA bar on mobile
  • Touch targets minimum 48x48px with 8px spacing
  • No horizontal scrolling on any device
  • Hero image uses real photos (not stock)
  • Color contrast meets WCAG 4.5:1 for text

Developer Checklist

  • GTM container installed (head + body)
  • Data layer initialized before GTM
  • GA4 configuration tag firing on all pages
  • Conversion Linker tag firing on all pages
  • Form submission conversion tracking working
  • Phone click tracking implemented
  • Enhanced conversions configured (user data)
  • Remarketing tag firing on all pages
  • GCLID stored in cookie for attribution
  • LCP under 2.5 seconds
  • INP under 200ms
  • CLS under 0.1
  • Images optimized (WebP with fallback)
  • Critical CSS inlined
  • HTTPS enabled with valid SSL
  • Schema markup added (LocalBusiness, FAQ)

Pre-Launch Testing

  • GTM Preview Mode - all tags firing correctly
  • GA4 Realtime - events appearing
  • Google Ads - conversions recording
  • Mobile testing on real devices (iOS + Android)
  • PageSpeed Insights score above 90
  • Form submission → data reaches CRM
  • Phone clicks working on all platforms
